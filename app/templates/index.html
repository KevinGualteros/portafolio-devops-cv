Conocimientos y Fundamentos

Infraestructura Cloud & DevOps

He desplegado este portafolio en AWS utilizando VPC, EC2 y RDS, y he definido infraestructura mediante Terraform. Durante mi formación práctica también conocí flujos de automatización con GitHub Actions. Para integrar el chatbot, ejecuté n8n en un contenedor Docker y conecté el servicio con un modelo de lenguaje de Groq. Sigo fortaleciendo mis habilidades en CI/CD, monitoreo, seguridad y optimización de costos cloud.

Desarrollo Full-Stack & Scripting

He construido la interfaz de este sitio con HTML, CSS y JavaScript, y su backend con Python y Flask. La aplicación gestiona formularios y comentarios, y utiliza MySQL para persistir la información; la base de datos se migró del entorno local a Amazon RDS. Este proyecto me ha permitido integrar rutas, plantillas dinámicas, conexión entre servicios y desarrollo full-stack en una aplicación funcional.

Análisis de Datos e IA

He trabajado académicamente con MATLAB, redes neuronales, clasificación de patrones y análisis de modelos de aprendizaje automático. En un proyecto de imágenes mamográficas utilicé el conjunto CBIS-DDSM, con procesos de balanceo y normalización, para comparar las arquitecturas CNN ResNet18, ResNet50 y DenseNet201 en la clasificación de tipos de calcificaciones. Los resultados deben interpretarse dentro del alcance experimental del proyecto, no como diagnóstico clínico.

Redes, Hardware & Automatización

Mi formación incluye direccionamiento IP y subnetting, estudio de cobertura radioeléctrica 5G, telecomunicaciones y conectividad. En automatización industrial he integrado un PLC Schneider Modicon M340, una interfaz HMI y una escena de Factory I/O mediante comunicación Modbus. Estos trabajos conectan los fundamentos de redes y comunicaciones con la electrónica, el control y las tecnologías operacionales (OT).

Machine Learning: Cáncer de Mama

Desarrollé en MATLAB una aplicación para visualizar mamografías del conjunto CBIS-DDSM y clasificar tipos de calcificaciones. Preparé los datos mediante balanceo y normalización, seleccioné los cinco tipos de calcificación más frecuentes y entrené y comparé redes convolucionales ResNet18, ResNet50 y DenseNet201. El repositorio contiene el código y la documentación del experimento; se trata de un proyecto académico y no de una herramienta de diagnóstico clínico.
